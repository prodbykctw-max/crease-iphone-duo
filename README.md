# CREASE

Neon air hockey built for the iPhone Duo fold.

- **Closed (5.4" outer screen):** pocket table — solo vs CPU (Easy / Normal / Hard).
- **Open (7.6" inner screen):** full table — the hinge is the center line, one player per half.
- Fold or unfold mid-match: the table resizes and the match continues.
- Power-ups on the crease: BIG paddle, MULTI puck, WALL over your goal. First to 7.

Single self-contained `index.html` — no build step, no dependencies. Plays in any modern mobile browser; Share → Add to Home Screen for full-screen.
