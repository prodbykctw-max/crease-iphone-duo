# CREASE player-experience principles

CREASE uses psychology to make play clearer, more satisfying, and more respectful of a player's time. It does not use artificial scarcity, variable-ratio rewards, pressure to purchase, or guilt-based return prompts.

| Principle | CREASE decision |
| --- | --- |
| Law of Effect | Immediate, legible feedback for goals, smashes, bank shots, and clean rallies. |
| Yerkes-Dodson | A player who falls three goals behind gets a brief reset cue, not a punishment or hidden difficulty spike. |
| Hick's Law | The first menu choice remains simple: solo or two players. |
| Weber-Fechner | Feedback intensity reflects the event: a smash or bank shot reads bigger than a normal return. |
| Parkinson's Law | Matches stay bounded at first to seven; no endless task or timer pressure. |
| Law of Least Effort | Touch must start on a paddle and keeps the exact grabbed point under the finger, preventing accidental snaps. |
| Zeigarnik Effect | End screens offer an optional rematch and name one small, player-controlled next goal. |
| Peak-End Rule | The end screen celebrates the best rally rather than only the win/loss result. |
| Serial Position | The most useful actions appear first and the menu is kept intentionally short. |
| Pygmalion Effect | Coaching is specific and encouraging: “one clean return,” never blaming language. |
| Benjamin Franklin Effect | No reciprocal-pressure mechanic is used. Feedback and sharing are optional and never block play. |

## Boundaries

- The full core game is free.
- Premium is a single optional purchase for cosmetic and clearly described extras; it never changes a player's ability to compete in a standard match.
- Players can stop, rematch, share, or ignore every optional prompt without penalty.
- No behavioural-profile targeting or personal-data collection is required for these features.
